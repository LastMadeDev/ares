The problem

          
Language models have barely seen Verse.

          
Out of the box, an agent guesses. In a UEFN island, a guess costs you a broken build, a frozen editor or a game thread that stalls in front of players.

        

        

          
Invents APIs that do not exist

          
Writes code that never compiles

          
Freezes the game thread

          
Reports “done” anyway

        


        

          
The fix

          
Three layers. Each one closes a gap.

        

        

          

            

              
            

            
Knowledge

            
Laws, skills and a copy-then-rename shapes catalogue lifted from Verse that ships in live islands. The Book of Verse is mirrored offline, and every compiler error code is indexed against Epic’s own test files.

            
  • 46 skills on demand
  • Shapes that compile, one per construct
  • Digest lookup before any new API

          

          

            

              
            

            
Guarantees

            
Hooks run on every edit, shell and MCP call. Rules ask; hooks enforce. The Stop gate holds every “done” up against the compiler’s real output since your last edit.

            
  • verse-lint on every .verse save
  • Guard denies freezes and crashes
  • Known errors recalled with their fix

          

          

            

              
            

            
Specialists

            
Narrow agents audit concurrency, persistence, memory, UI wiring and in-island purchases. They share one output contract and loop until the verdict is CLEAN.

            
  • 10 agents, one contract
  • Fan out in parallel, fix one blocker at a time
  • Read-only auditors never edit

The loop

          
Every edit runs the gauntlet.

          
The agent cannot end its turn on a red build. If no green build happened since the last edit, the Stop gate sends it back through /build-check: BuildAll, digest proof, log proof, lint.

          
Compiles never means works. Behaviour is proven in a playtest with [TEST] and [EVENT] marks read straight from the log, or it lands on your test list.

You plan the next batch and test the last one.

Execute to the end. No questions.

                
One ticket, end to end: edits, Verse builds over MCP until green, assets, device placement, saves, playtest sessions, proof of every acceptance check, an island commit, a Linear report and kit lessons. /work-long does the same while you are away from the PC.

  • editor-lock.ps1 keeps them off one UEFN at a time
  • Ambiguity is decided toward the goal and recorded

Every agent makes the next one sharper.

                
When a fix costs real time, the agent writes the lesson into the kit: search first, sharpen before adding, one fact per file. kit.ps1 ship commits, rebases, fast-checks and pushes. CI runs the full suite, and every machine pulls it at session start.

                
  • Budgets keep always-on context under 8 KB
  • Every Verse code fence linted in CI
  • Rules that stop firing get retired weekly

    Keeping it true
    
          
    It learns from its own mistakes.
    
          
    Failed tool calls, Verse errors, audit findings, art-director rejections and your corrections land in a lesson ledger. A known mistake gets its one-line fix injected the moment it recurs.
    
        
    
        
    
          
    1Mistake
    A build error, a crashed batch, a correction from you.
    
          
    
          
    2Ledger
    Logged per project with the fix that worked.
    
          
    
          
    3Recall
    Seen again? The fix is injected before the retry.
    
          
    
          
    4Rule
    Made twice? It becomes one sharper rule, shipped to every machine.

    Safety
    
            
    Full autonomy, with hard edges.
    
            
    The guard denies only what would hang, freeze or crash a run. Everything else is allowed, and hooks never ask. Account-safety lines are skipped around, never crossed.
    
          
    
          
    
            
    mcp_authhangs the session
    
            
    reload from diskfreezes UEFN for minutes
    
            
    > 200 writes / callsplit into chunks, then save
    
            
    save_assets([])saves every session’s dirty packages
    
            
    3× same failurethe 4th identical call is denied
    
          
    
          
    
            
    Epic account-safety lines it never crosses
    
            
      
              
    • Machine and account. No input automation on the game client, no anti-cheat, no reading or injecting into Epic processes, no asset extraction, no private endpoints, no alt accounts.
      • 
              
    • Island content. No gambling shapes, no links or calls to action outside the game, no misleading metadata, no exploits, no copied islands or unlicensed IP.
      • 
              
    • Who does what. You own publishing, the Creator Portal, ratings answers, payouts and team invites. Agents may draft; you submit.
      • 
            
    
          
    
          
    Private by default. Hooks and tools run locally and never send your island anywhere. The only network traffic is the kit syncing itself.
    
        
    
      
    
    
    

    
    
    
      
    
        
    
          
    Quick start
    
          
    Four commands. Every island on every machine.
    
          
    One install puts ARES in ~/.claude. Updates are git pull and the installer again; anything you edited by hand is backed up.
    
        
    
        
    
          
    
            
    PowerShell
    
            
    # clone to this exact path; the commands expect it
git clone https://github.com/LastMadeDev/Project-ARES.git "$env:USERPROFILE\Documents\UEFNCLAW"
cd "$env:USERPROFILE\Documents\UEFNCLAW"
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
claude mcp add --transport http --scope user unreal-mcp http://127.0.0.1:8000/mcp

      2. 
            
    2. Build Verse onceSo the compiler digests exist.
      3. 
            
    3. Start Claude Code in Content\With the digests attached via --add-dir.
      4. 
            
    4. Run /project-syncMaps your Verse and seeds island config.
      5. 
          
    
        
    
        
    Early access: the repository is private for now. Once your request is approved you get an invite, and the clone above works after you accept it.
    
        
    Requires Windows 10 or 11, Git, Claude Code, Python 3 and UEFN with MCP Toolsets enabled. Linear is optional, for plan and work modes.

    FAQ
    
          
    Questions, answered straight.
    
        
    
        
    
          
    Is ARES made by or affiliated with Epic Games or Anthropic?
    No. Project ARES is an independent project by LastMade. It is not sponsored, endorsed, or administered by Epic Games, Inc., and it is not affiliated with Anthropic.
    
          
    Does it play Fortnite for me?
    No. ARES drives the UEFN editor over Epic’s MCP Toolsets and reads the editor log. It never automates input on the game client and never touches anti-cheat or Epic processes. Playing your island is your job, and /test-pass turns it into one checklist.
    
          
    Does my island leave my machine?
    No. Hooks and tools run locally. The kit syncs itself with its own repo at session start (you can turn that off), and Claude Code talks to Anthropic as it always does.
    
          
    Will it publish my island or touch my Creator Portal?
    Never. Publishing, the Creator Portal, ratings answers, payouts and team invites stay with you. Agents may draft text for them; you submit it.
    
          
    Why Windows only?
    UEFN runs on Windows, and the hooks and tools are PowerShell and Python built around it.
    
          
    What does “proves it” actually mean?
    A change is not done until the compiler’s digest shows a green build since the last edit, and behaviour is either proven by [TEST] marks in a playtest log or put on your test list by name. The Stop gate checks the first part on every turn.
    
          
    Can I sell islands built with it?
    Yes. Islands you build with ARES are yours, including ones that earn money. What needs a commercial license is reselling ARES itself.
